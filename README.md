# Chrono Crystal — Game Boy RPG (GBDK-2020)

เกม RPG ขนาดเล็กสำหรับ Game Boy ที่พัฒนาต่อจากต้นแบบใน `main.c` เดิม
โดยทำครบทั้ง 6 ระยะตามแผนใน [`ChronoCrystal.md`](ChronoCrystal.md)
ตัวเกม build แล้วพร้อมเล่นที่ `game.gb`

---

## 1. เรื่องย่อ

ในดินแดน **Aethelgard** ปีศาจ **Malakor** ได้ขโมย **Chrono Crystal**
คริสตัลที่ค้ำจุนเวลาและความสมดุลของโลกไป ทำให้มอนสเตอร์กลายพันธุ์
ผู้เล่นรับบทนักผจญภัยฝึกหัดที่ต้องออกเดินทาง เก็บเลเวล และชิงคริสตัลกลับคืนมา

| Act | สถานที่ | สิ่งที่พบ |
| :-- | :-- | :-- |
| 1 | Green Plains | Slime, เฒ่าผู้แก่ (NPC รักษา HP/MP) |
| 2 | Whispering Woods | Skeleton, Bat |
| 3 | The Void Castle | Malakor (บอสใหญ่) และ Chrono Crystal |

เดินออกทางขวาของแผนที่เพื่อไป Act ถัดไป และเดินกลับทางซ้ายเพื่อย้อนกลับ

## 2. วิธี Build

ต้องมี **GBDK-2020** (โปรเจกต์นี้ใช้ที่ `C:/gbdk`)

```bash
# วิธีที่ 1: ใช้ Makefile
make

# วิธีที่ 2: เรียก lcc ตรง ๆ
/c/gbdk/bin/lcc -Wa-l -Wl-m -Wl-j -Wl-yt0x1B -Wm-ya1 \
  -o game.gb main.c assets.c screen.c player.c map.c battle.c sfx.c save.c
```

- `-Wl-yt0x1B` กำหนดตลับเป็น **MBC5 + SRAM + Battery** (จำเป็นสำหรับระบบเซฟ)
- `-Wm-ya1` กำหนด SRAM 1 ธนาคาร (8 KB)
- ถ้า GBDK อยู่ที่อื่น ให้แก้ `GBDK_HOME` ใน `Makefile`
- `make clean` ลบไฟล์ build ที่ไม่จำเป็น

## 4. ระบบที่พัฒนา (ตรงตามแผน)

| Phase | สถานะ | รายละเอียด |
| :-- | :--: | :-- |
| 1. Modularize | ✅ | แยกโมดูลจอ, ผู้เล่น, แผนที่, การต่อสู้, เสียง, เซฟ และ asset |
| 2. Background Maps | ✅ | แผนที่ 3 Act ขนาด 20×18 ไทล์ พร้อมไทล์หญ้า/น้ำ/ต้นไม้/ปราสาท/คริสตัล |
| 3. Collision | ✅ | ตรวจการชนทั้งสี่มุมของสไปรท์กับไทล์ทึบ ใช้กับทั้งผู้เล่นและศัตรู |
| 4. Deep Battle | ✅ | เมนู FIGHT / MAGIC / ITEM / RUN, ค่า MP, โพชั่น, หนี, เลเวลอัป |
| 5. Sound | ✅ | SFX ผ่านช่อง 1/4 และ BGM ลูปผ่านช่อง 2 |
| 6. Save RAM | ✅ | เซฟ/โหลดสถานะผ่าน SRAM ของตลับอัตโนมัติ |

### 4.1 แผนที่และ NPC
- แผนที่ถูกเก็บเป็นข้อความ ASCII ใน `assets.c` แล้วแปลงเป็นไทล์ตอน `map_load()`
- ไทล์ที่เดินผ่านไม่ได้: ต้นไม้, น้ำ, กำแพง, เสา, ป้าย, คริสตัล
- ทางออกระหว่าง Act อยู่ที่แถว 8–9 ของแผนที่ (ช่องทางเดิน)
- เฒ่าผู้แก่ใน Green Plains จะฟื้น HP/MP ให้เต็มและบันทึกเกมเมื่อกด A ใกล้ ๆ
- มีศัตรูเดินไล่ผู้เล่น 1 ตัวต่อแผนที่ (บอสอยู่ในปราสาทและอยู่กับที่)

### 4.2 การต่อสู้
คำสั่งของผู้เล่น:

| คำสั่ง | ผล |
| :-- | :-- |
| FIGHT | ดาเมจ = `max(1, ATK ผู้เล่น − DEF ศัตรู)` |
| MAGIC (3 MP) | ดาเมจ = `max(1, ATK + 6 − DEF)` |
| ITEM | ใช้โพชั่นฟื้น 12 HP (เริ่มมี 3 ขวด) |
| RUN | หนีสำเร็จ 50% (บอสหนีไม่ได้) |

ศัตรูจะโจมตีกลับหลังผู้เล่นลงมือ ถ้า HP หมดจะฟื้นเต็มและกลับจุดเริ่มต้นของพื้นที่
เมื่อชนะจะได้ EXP, มีโอกาส 25% เก็บโพชั่นได้, และเซฟอัตโนมัติ

ค่ามอนสเตอร์:

| ชื่อ | Lv | HP | ATK | DEF | EXP |
| :-- | :-: | :-: | :-: | :-: | :-: |
| Slime | 1 | 12 | 4 | 1 | 8 |
| Skeleton | 3 | 22 | 6 | 2 | 20 |
| Bat | 2 | 16 | 5 | 1 | 15 |
| Malakor | 8 | 80 | 12 | 6 | 100 |

เลเวลอัป: `max HP +5, ATK +2, DEF +1, max MP +2` และฟื้น HP/MP เต็ม
EXP ที่ต้องใช้ในเลเวลถัดไปเพิ่มครั้งละ 10

## 6. ระบบเซฟ (SRAM)

- ข้อมูลอยู่ที่ `0xA000` ของ SRAM (MBC5, 8 KB)
- ตรวจสอบด้วย magic `"CC"` และ version `1`
- บันทึกอัตโนมัติเมื่อ: ชนะการต่อสู้, เปลี่ยน Act, และคุยกับเฒ่าผู้แก่
- ลบเซฟอัตโนมัติเมื่อปราบ Malakor (จบเกม)
- ข้อมูลที่บันทึก: เลเวล, HP/MP, EXP, ค่าพลัง, จำนวนโพชั่น, จำนวนชนะ, พื้นที่ และพิกัด

ลำดับข้อมูลใน SRAM (packed struct):

```
offset 0   : magic0 'C'
offset 1   : magic1 'C'
offset 2   : version (1)
offset 3   : level
offset 4-5 : hp
offset 6-7 : max_hp
offset 8-9 : exp
offset 10-11: next_level_exp
offset 12  : attack
offset 13  : defense
offset 14  : mp
offset 15  : max_mp
offset 16  : potions
offset 17-18: wins
offset 19  : area
offset 20  : x
offset 21  : y
```

> หมายเหตุ: ตัวเลข offset ด้านบนอธิบายลำดับเชิงตรรกะของ struct
> ไม่ใช่ byte offset ที่รับประกันข้ามเวอร์ชันคอมไพเลอร์

## 7. การทดสอบที่ทำแล้ว

- Build ด้วย GBDK-2020 ผ่านโดยไม่มี warning/error
- ROM ขนาด 32 KB, ใช้ ROM แบงก์ 0 ประมาณ 9 KB และ WRAM ประมาณ 429 ไบต์
- ทดสอบรันจริงด้วย PyBoy (headless) โดยอ่านค่าจาก RAM ของเกม:
  - boot เข้า Title และกด A เริ่มเกมได้
  - เดินชนน้ำถูกบล็อก, เดินในพื้นที่ว่างได้
  - เปลี่ยน Act ไปป่าและย้อนกลับได้
  - เปิด/ปิดเมนูสถานะด้วย SELECT/B
  - ชนศัตรูแล้วเข้าฉากต่อสู้, FIGHT ลด HP ศัตรู, ศัตรูโจมตีกลับ
  - MAGIC ใช้ 3 MP และสังหารศัตรูได้, ได้ EXP/จำนวนชนะ
  - เซฟลง SRAM (`CC` magic) และโหลด Continue กลับมาสถานะเดิมได้
  - ปราบบอสแล้วเข้าหน้าจบเกมและเซฟถูกลบ

ข้อจำกัด: ยังไม่ได้ทดสอบเสียงด้วยการฟังจริง (ตรวจเฉพาะการเขียนรีจิสเตอร์),
แผนที่แต่ละ Act เป็นหนึ่งหน้าจอไม่มี scrolling, และมีศัตรูเดินได้ครั้งละหนึ่งตัว
